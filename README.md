# Kid games

Des jeux pour les enfants, faits pour le plaisir et pour explorer des idées : prototypes et versions
d'essai. Les jeux aboutis, pensés pour la classe, sont publiés sur
[edu-fpar.github.io](https://edu-fpar.github.io/) (Star Nav, Strange Mind · Défis éclair).

## Lancer en local

Aucune dépendance : HTML, JavaScript (modules ES) et Canvas 2D. Il faut un serveur web (les modules ES
ne se chargent pas en double-clic) : `node tools/serve.mjs` puis http://localhost:8765/, ou UwAmp :
http://localhost/kid-games/.
